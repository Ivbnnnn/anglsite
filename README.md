# anglsite

Тренажёр английского: неправильные глаголы, тематический словарь, упражнения, теория, личный список и карта слов. Сайт полностью статический и работает на GitHub Pages без Python, Docker, API-ключа и базы данных.

## Публикация

Workflow `.github/workflows/pages.yml` проверяет сайт, собирает только файлы HTML/CSS/JS и публикует их при каждом push в `main`. В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. Адрес проекта: `https://ivbnnnn.github.io/anglsite/`.

Локально: `npm test` и `npm run build`. Для просмотра откройте `index.html`. Для браузерного переводчика Chrome используйте опубликованный HTTPS адрес.

## Личные данные и модели

Свои слова и невыученные глаголы хранятся в `localStorage` конкретного браузера и адреса. На странице **Мои слова** есть экспорт и импорт JSON: скачайте копию на старом адресе и импортируйте на GitHub Pages. Импорт добавляет новые записи, сохраняя существующие.

Знакомые фразы подсказываются из встроенного словаря. Для новых фраз кнопка **Предложить перевод** запускает встроенный переводчик Chrome, если он доступен, либо загружает `Xenova/opus-mt-en-ru` через Transformers.js и выполняет перевод в браузере. Кнопка **Найти похожие по смыслу** на карте загружает `Xenova/multilingual-e5-small` и сравнивает слова по векторам. Загрузка моделей начинается только по нажатию; при первом запуске нужны интернет и свободное место в кэше браузера. Переводы проверяйте перед сохранением.
